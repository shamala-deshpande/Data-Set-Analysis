# Data-Set-Analysis
# Retail Sales & Operations Analytics (Maharashtra Dataset)

## 📌 Overview
An exploratory data analysis and interactive dashboard project built in **Microsoft Excel** using a **500-order retail sales dataset** (Jan 2026 – Oct 2026) across 10 cities in Maharashtra.

## 🛠️ What I Did
* **Data Cleaning:** Standardized inconsistent city names (`Pune`, `Mumbai`) and order statuses (`Completed`).
* **KPI Calculations:** Created formulas for **Gross Sales** (`Quantity × Unit_Price`), **Discount Amount**, and **Delivery Days** (`Delivery_Date − Order_Date`).
* **Pivot Table Analysis:** Summarized data across products, cities, sales channels, delivery times, and customer ratings.
* **Dashboard & Visuals:** Built **Bar, Column, Line, and Pie charts** with **interactive Slicers** for dynamic filtering.

## 📊 Key Insights
* **Revenue:** **₹1.57 Cr** Gross Sales and **₹1.33 Cr** Net Sales across 500 orders.
* **Top Cities:** **Thane** (₹16.89L) and **Karad** (₹15.88L) generated the highest Net Sales.
* **Top Products:** **Laptops** (251 units), **Office Desks** (240 units), and **Office Chairs** (238 units) led unit volume.
* **Channels & Delivery:** **Mobile App** led sales (₹50.58L), while **Retail Store** delivered fastest (**6.33 days** avg vs. **6.61 days** overall).
* **Customer & Order Health:** Average rating was **2.93 / 5**, with high cancellation (134) and return (116) counts flagging an area for improvement.
